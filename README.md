Historical C++ and Python assignments, including linked lists, stacks, trees and sorting exercises.

## Layout

Assignments retain their original `a1/`–`a12/` organization. Some archives contain a repeated inner folder (for example `a7/a7/`); paths are preserved because the exercises and accompanying data refer to their local directories.

Source files, assignment PDFs and text data are retained. Generated Windows executables are excluded from the current tree.

## Running an exercise

C++ assignments need a C++ compiler; Python exercises need a compatible Python interpreter. Treat each assignment as a separate program, read its inputs first, and link the helper implementation files it uses. Several files contain independent entry points, so compiling all files together is inappropriate.

The exercises have not all been rebuilt or behavior-tested during the portfolio organization pass. This repository represents coursework rather than a single supported application.
